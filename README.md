# 💰 Finance Tracker

A simple multi-page Finance Tracker built with **React** that allows users to manage income and expense transactions. This project focuses on reinforcing React fundamentals while following a clean, component-based architecture.

---

## 🎯 Goal

Build a Finance Tracker using React that demonstrates:

- React Components
- Props
- useState
- React Router
- Controlled Forms
- CRUD Operations
- Array Methods (`map`, `filter`, `reduce`)
- Component Composition
- Clean Project Architecture

---

## 🛠 Technology Stack

- React 19
- Vite
- React Router
- CSS (or CSS Modules)
- Local State (`useState`)

> **Note:** This project uses local state for simplicity. It can later be refactored to use the Context API for global state management.

---

## 📌 Features

- Dashboard with financial summary
- Add new transactions
- View all transactions
- Edit existing transactions
- Delete transactions
- Filter by Income or Expense
- Calculate:
  - Total Income
  - Total Expenses
  - Current Balance
